# 运维说明

## 服务器目录

| 目录或文件 | 用途 |
| --- | --- |
| `/usr/local/bin/hysteria-maintain` | 运维命令，卸载服务后保留 |
| `/usr/local/share/hysteria-maintain/assets/` | 安装用网站 ZIP 与校验文件，卸载后保留，用于再次安装 |
| `/usr/local/bin/hysteria` | 官方 Hysteria 程序 |
| `/etc/hysteria/config.yaml` | 服务端配置，包含密码 |
| `/var/lib/far-field-hysteria/` | 管理标记、域名、密码、官方安装脚本、ACME 证书及重装前配置备份 |
| `/var/www/far-and-field/` | 解压后的网站文件 |

首次安装从项目的 `assets/far-and-field.zip` 提取网站，并保存一份安装包到服务器。以后通过已安装菜单重新安装时，自动读取服务器保留的包，不需要 `/home/ubuntu/dist` 或本机其他目录。

现有 JP1 旧版本部署可以在上传完整项目后，运行项目中的 `sudo bash ./hysteria-maintain`，选择 `1` 并确认重装来安装新版菜单与持久网站包。它会备份配置并保留原密码和现有网站。旧配置没有域名记录文件时会读取原 ACME 配置中的域名。

## 状态页

选 `2` 显示服务运行时间、版本、开机启动、域名、公网 IPv4/IPv6、域名的 A/AAAA 解析地址、实际配置的 UDP/TCP 端口监听、正在提供的证书和本机 HTTPS 检查。公网地址是出口地址，多 IP 或 NAT 环境下不保证与全部域名记录相同。“未获取”不代表没有 IPv6，“无记录或查询失败”也不直接证明 DNS 未配置。

服务停止、端口缺失、证书/网站检查失败显示异常；证书剩余不足 14 天、未启用开机启动、近期协议断连或超时显示提醒。最近 10 分钟按客户端断连事件计数，同一断连造成的多条 TCP 转发错误不会重复计算；网站 TLS 握手失败保留在菜单 `3` 的详细日志中。

无提醒只表示列出的检查通过，不表示全部日志没有错误。状态页使用北京时间，证书到期显示 UTC 日期。本机检查不证明手机到 VPS 的公网 UDP 链路可用，仍需外部客户端验证。

## 网站与证书

网站、Hysteria 代理共用官方服务进程，各自使用向导指定的 TCP / UDP 端口（默认 443）。TCP 80 留给 ACME HTTP 验证，未配置常驻 HTTP 网站或 HTTP 跳转。非默认网站端口应使用 `https://你的域名:网站端口/` 访问。

菜单每次读取配置中的 `listen` 和 `masquerade.listenHTTPS`，用于端口检查、网站检查和证书查询；客户端参数与分享链接使用代理 UDP 端口。旧版 443 部署继续兼容。重装保留现有端口，改变现有配置前应自行备份并调整云端及系统防火墙。

本项目不在服务器设置固定上下行带宽；客户端可按自身网络设置。配置变动需要重启服务，重启会短暂中断代理连接。

## 升级

菜单 `7` 从 `https://get.hy2.sh/` 下载官方安装脚本，查询最新稳定版本后再询问是否升级。当前已是最新版时，可以取消，或确认重装同一版本以验证安装流程。升级前会在 `/var/lib/far-field-hysteria/upgrade-backup-*/` 保存程序、配置、密码、官方安装脚本及服务文件；失败时尝试自动回滚。成功后仍保留备份，便于审计。脚本不会改动网站与客户端密码，并会检查版本、监听和本机 HTTPS。请通过外部客户端另行确认公网 UDP 连接。

## 卸载

菜单 `6` 会询问确认，随后调用本次安装时保存的官方卸载脚本，并清理项目管理的配置、网站和凭据。菜单、网站 ZIP 以及防火墙规则保留，可再次选择安装。不要在项目管理的 `/etc/hysteria/` 下混放其他服务的配置。
